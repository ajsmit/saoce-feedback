# SAOCE feedback

Report a problem, suggest an improvement or ask a question about
[Southern African Ocean Conditions & Extremes](https://www.saoce.org/).

[Open a feedback form](https://github.com/ajsmit/saoce-feedback/issues/new/choose)
or [browse existing feedback](https://github.com/ajsmit/saoce-feedback/issues).
GitHub provides discussion threads, reactions, notifications and progress tracking
for each report. A GitHub account is needed to submit or comment.

Reports here are public. Include only information you are comfortable sharing.
For private feedback, sensitive information or help without a GitHub account,
[email the maintainer](mailto:ajsmit@uwc.ac.za).

This repository holds feedback and forms. SAOCE application source, visitor logs,
credentials and unpublished research are not published here.
